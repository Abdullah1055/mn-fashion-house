# Project Goal

Build a premium, modern, fast and SEO-friendly fashion e-commerce platform
for MN Fashion House.

The platform will allow customers to browse products, add products to cart,
place orders and communicate with the business.

Store management will be handled completely from an Admin Dashboard.

No coding knowledge should be required to manage products.
