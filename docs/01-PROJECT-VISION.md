# Project Vision

MN Fashion House will become a premium online fashion destination
for Bangladesh.

The goal is not only selling clothes.

The goal is building a trusted fashion brand.

The website should look modern,
minimal,
premium,
fast,
and luxurious.

Inspired by

- Zara

- COS

- Massimo Dutti

- Apple

The customer experience should be simple.

Less clicks.

Fast loading.

Professional design.

The website should be maintainable for years.

Every feature should be scalable.

Future features must not require architecture changes.
